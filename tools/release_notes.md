The helper for Windows 10 and 11, with Lightroom Classic. Instructions: [user guide](https://github.com/Bipedal/BMD-MicroColorPanel-Tools/blob/main/docs/GUIDE.md).

The program isn't signed, so Windows may warn: **More info > Run anyway**. GitHub built it from the source of this
tag; `.sha256` is the checksum of the zip.

What's new: [CHANGES.md](https://github.com/Bipedal/BMD-MicroColorPanel-Tools/blob/main/CHANGES.md). **Layers work differently**: what a layer
doesn't set now does nothing (a switch per layer keeps the old behaviour). After updating, **Settings > Replace the plugin**
and restart Lightroom.

Tried with one panel (firmware 2.2.0) on Windows 11 and Lightroom Classic 16.0 in English.
